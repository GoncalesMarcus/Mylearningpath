# Materiais

Guarde aqui os arquivos de estudo (PDFs, imagens, planilhas), de preferência em uma pasta por caderno:

```
materials/econ/
materials/general/
materials/lang/
```

Depois, aponte para eles no `data/notebooks.js`, por exemplo `url: "materials/econ/math-notes-1.pdf"`.

Arquivos muito grandes (acima de ~50 MB) ficam melhor no Google Drive; o GitHub recusa arquivos acima de 100 MB.
